Simulation 04 · Loss Functions, Backpropagation & Why We Focus on Inference

How AI Learns: Gradient Descent vs. Frozen Inference

To train a neuron, we measure how wrong its prediction ŷ is using a Loss Function, compute partial derivatives ∂L/∂w via the chain rule (Backpropagation), and nudge weights opposite the slope: w ← w - η(∂L/∂w). Run live training steps below—and see why running training on an FPGA is a massive headache compared to inference.

Why Our Committee Builds Inference Hardware (And Why Training on an FPGA Is a Headache)

Requirement Inference (Our Focus on FPGA) Training (Done in Cloud / GPUs)
Computation Direction Forward pass only (x → ŷ). Clean streaming pipeline. Forward pass + Backward pass + Weight update (~3× compute).
Intermediate Activations Discarded immediately as soon as the next layer consumes them. Must save every layer's activations in massive memory until backprop reaches them!
Weights Memory Completely frozen (Read-Only constants in on-chip BRAM/ROM). Constantly rewritten every batch; must also store gradient & optimizer buffers.
Number Precision Compact 8-bit or 16-bit fixed-point integers work great. Requires high-dynamic-range floating-point (FP32 / BF16) so tiny gradients don't vanish to zero.
